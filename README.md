# Волонтерський транскрибатор для Windows

Невелика програма для мого студентського проєкту [Student Schedule](https://schedule.kpi.lat). Вона допомагає
розпізнавати українські лекції на комп’ютерах волонтерів і повертає готовий текст із таймкодами.

[**Завантажити інсталятор для Windows (.exe)**](https://github.com/pabl0cus/student-schedule-worker-windows/releases/latest)

## Встановлення

1. Завантаж `StudentScheduleWorker-0.1.0-Setup.exe` зі сторінки останнього релізу.
2. Запусти інсталятор і відкрий **Student Schedule Worker**.
3. Вкажи адресу `https://schedule.kpi.lat` та особистий токен, який видав адміністратор.
4. Обери години, коли програмі можна працювати.

Інсталятор поки не має платного цифрового підпису, тому Windows може показати попередження SmartScreen.

## Як це працює

- програма живе в системному треї й працює лише у вибраний час;
- завантажує тільки аудіодоріжку лекції, без відео та метаданих;
- розпізнає українську мову через Whisper `large-v3`;
- використовує NVIDIA GPU, якщо він доступний, інакше переходить на CPU;
- надсилає на сервер текст із таймкодами та видаляє тимчасове аудіо.

Під час першої роботи програма завантажить модель Whisper. Для неї потрібно кілька гігабайтів вільного місця
та доступ до Hugging Face. На CPU транскрибація працюватиме значно повільніше.

Новий клієнт спочатку стоїть у режимі **«Ніколи»**. Він не бере завдання, доки волонтер сам не вибере інший
режим або розклад.

## Приватність

Комп’ютер волонтера тимчасово отримує аудіо лекції. Технічно його можна скопіювати, тому токени варто видавати
лише людям, яким ви довіряєте, а користувачів сервісу потрібно попереджати про волонтерську обробку.

Особистий токен зберігається у Windows Credential Manager і не записується у звичайний конфігураційний файл.
Його можна відкликати в адмін-панелі в будь-який момент.

## Локальні дані

Модель, налаштування, тимчасові файли й логи зберігаються в
`%LOCALAPPDATA%\student-schedule-worker`. Незавершені аудіофайли прибираються під час наступного запуску.
